About Example technical SEO

Example publishes original documentation for site owners who want crawlable HTML, honest structured data, and measurable field metrics. This page is a fixture used to lock scanner behaviour. It includes enough visible prose so the first HTML is extractable. Search engines and AI search crawlers can read this paragraph without executing JavaScript.

What this fixture covers

Titles, meta descriptions, a self-referencing canonical, one H1, heading hierarchy, Organization plus a two-item BreadcrumbList in a top-level JSON-LD array, internal links, and Open Graph tags. It does not invent star ratings. It does not recommend FAQPage as a Google rich result.

How to use the fixture

Run analysePage against this file offline. Assert check ids and statuses, not marketing prose. A parse-only JSON-LD pass is not rich-result eligibility. BreadcrumbList must have at least two ListItems.

Additional paragraphs keep the word count above the thin-content heuristic without claiming that word count is a Google ranking penalty. Comprehensive documentation helps humans and makes the first HTML useful to crawlers.

Link to the docs hub and the pricing page so internal linking looks healthy.
